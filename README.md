# AI Analytics Dashboard

A learning project for an AI usage analytics dashboard.

This repository will contain:

- **`web/`** — React + TypeScript frontend (Vite)
- **`api/`** — Express + TypeScript backend (PostgreSQL)

The frontend displays KPIs, charts, and usage data. The backend serves that data from a database.

## Current status

The Vite React TypeScript app in `web/` is set up. The Express API has not been created yet.
